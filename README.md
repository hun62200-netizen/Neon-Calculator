# Neon Calculator

A simple neon-themed calculator Android project built with a WebView and HTML/CSS/JavaScript.

## Build APK on GitHub (using an Android phone)

1. Create a GitHub repository and upload **the extracted contents** of this ZIP (not only the ZIP file).
2. Open the repository's **Actions** tab.
3. Choose **Build Neon Calculator APK** and tap **Run workflow**.
4. When the workflow finishes successfully, open that run and download the `Neon-Calculator-APK` artifact.
5. Extract the downloaded artifact ZIP on your phone to get `app-debug.apk`.

The project uses Gradle and Android SDK in GitHub Actions. The first build may take several minutes.
